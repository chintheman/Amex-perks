# Hero image

`amex-platinum-card.png` — the official Singapore Platinum Card art, 480 × 304
transparent PNG, from American Express's own CDN:

    https://icm.aexp-static.com/acquisition/card-art/NUS000000237_480x304_straight_withname.png

It is product artwork used editorially to identify the card this guide is about.
The guide states in its footer that it is unofficial and not affiliated with or
endorsed by American Express. Swap it for an original photo if you would rather
not use Amex's asset.

The hero renders this file when it exists and falls back to a dashed placeholder
when it does not — the page works either way. The frame is 310 × 195 CSS pixels
at a 1.586 aspect ratio.
